Want to test the `capacitor-admob-nextgen` but don't want to clutter your local development environment? You can easily compile and test our examples directly from the repository using our free public build engine.

Just head over to **[Public SwapLab Builder](https://public.swaplab.net)** and follow the quick steps below based on your framework.


### ⚡ Fastest testing

1. **Project Framework Type:** Select `Capacitor`
2. **Project Source:** Select `Git Repository`
3. **Repository URL:** Copy and paste **one** of the template URLs below:

```bash
https://github.com/swaplab-engine/capacitor-admob-nextgen-template
```

4. **Confirmation:** Check the box *`I confirm this is a public GitHub repository`*
5. **Image Name:** Select `capacitor-build-android-engine`
6. **Reference (Image Tag):** Select `v2.1.1`
7. Click **`🚀 Upload and Build`**

---
⏳ **Wait for 3-5 minutes.** Once the build is complete, you can download the **Debug APK**, install it on your device, and test the ads immediately!

Let me know if you encounter any issues during testing. Happy coding!
